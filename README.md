# StormCracker Suite (Autonomous WiFi Auditor)

Welcome to the **StormCracker Suite**, a production-grade, two-part security auditing framework designed for automated wireless network penetration testing and high-performance hardware-accelerated password recovery.

## 🚀 The Architecture

This suite abandons manual CLI workflows in favor of highly automated Python engines. It is split into two distinct modules:

### 1. The Autonomous Capture Engine (`wifi_auditor.py`)
*Requires: Kali Linux / Ubuntu with a monitor-mode capable WiFi adapter.*

A fully autonomous daemon that scans the airspace, identifies targets, and methodically executes deauthentication attacks to harvest WPA2 handshakes.
- **Hands-Free**: Automatically cycles through targets, managing its own timers and validation checks.
- **Smart Target Verification**: Checks the `handshakes/` directory to skip networks that have already been compromised or captured.
- **Batch Processing**: Automatically converts and appends all captured `.cap` files into a single, highly optimized Hashcat batch file (`batch_hashes.hc22000`).
- **Sleep Prevention**: Implements native Linux `systemd-inhibit` to prevent the system from sleeping during long, overnight surveillance operations.

### 2. StormCracker GUI Engine (`win_cracker.py`)
*Requires: Windows or Linux.*

A premium, modern Graphical User Interface built on `customtkinter` that wraps Hashcat in a beautiful, cross-platform dashboard.
- **Hardware Agnostic**: Runs natively on Kali Linux utilizing system tools, or deploys as a standalone Windows `.exe` utilizing embedded Hashcat binaries.
- **Real-Time Telemetry**: Parses modern Hashcat v7 machine-readable output to display live Hash Rates, Progress Bars, GPU Temperatures, and Candidate Testing animations.
- **Resilient Sessions**: Built-in pause/resume functionality using Hashcat's `.restore` feature. It safely handles interruptions so you never lose your progress on massive wordlists.
- **Automated Extraction**: Automatically parses the `win_cracker.potfile` upon exhaustion and logs the cracked plain-text passwords securely.

## 🛠️ Quick Start

### Running the Auditor (Linux)
Ensure you have the `aircrack-ng` suite and `hcxtools` installed.

The `wifi_auditor.py` script can be run entirely autonomously, or strictly configured via CLI flags:

```bash
# Autonomous Mode: Scans all networks, targets strong signals, and attempts cracks automatically
sudo python3 wifi_auditor.py

# Target Mode: Attack only a specific network
sudo python3 wifi_auditor.py -t "My Network"

# Filter Mode: Only attack networks with strong signals (-70 dBm or higher)
sudo python3 wifi_auditor.py -s -70

# Capture Only Mode: Capture handshakes without engaging Hashcat
sudo python3 wifi_auditor.py --skip-crack
```

Use `sudo python3 wifi_auditor.py --help` to see all available options, including manual interface selection (`-i`) and timeout controls (`--timeout`).

### Running the Cracker (Cross-Platform)
Ensure you have `customtkinter` installed (`pip install customtkinter`).
```bash
python3 win_cracker.py
```
Use the GUI to select your `batch_hashes.hc22000` file generated by the auditor, select your wordlist, and click **ENGAGE**.

## 📦 Compilation & Deployment

This repository features a fully automated **CI/CD Pipeline via GitHub Actions**. 
Every time you push code to the `main` branch, GitHub Actions will automatically compile the Linux binaries (into a `.deb` package) and the Windows GUI (into `WinCracker_Setup.exe`), and push them directly to the **GitHub Releases** tab!

If you prefer to compile manually, the StormCracker GUI is designed to be easily compiled into a standalone Windows Executable with a professional `Setup.exe` installer. 

Please refer to the **[COMPILATION_GUIDE.md](./COMPILATION_GUIDE.md)** for step-by-step instructions on how to manually package the application.
